# Vision & Roadmap - Gastroshows Admin

## 📱 Interfaz de Usuario (UI/UX)
### Menú Estilo Odoo / Smartphone OS
- **Concepto**: El menú principal debe comportarse como el lanzador de aplicaciones de un smartphone o el dashboard de Odoo. 
- **Interacción**: Un icono circular flotante que sirve de punto de entrada único.
- **Animaciones**: 
  - Al pasar el cursor (hover), el círculo crece suavemente de 30px a 60px en 0.75s.
  - Al hacer clic, el icono tiene un efecto de "explosión" o desvanecimiento.
  - El menú aparece deslizándose de izquierda a derecha con un efecto de *fade-in* progresivo.
- **Persistencia**: El estado del menú debe guardarse automáticamente.

## 🤖 Inteligencia Artificial & Data Analytics
### Modelo de Entrenamiento Personalizado
- **Objetivo**: Crear un modelo de IA que aprenda de los datos específicos de Gastroshows.
- **Funcionalidades**:
  - Sugerencia de campañas de marketing basadas en el histórico.
  - Generación de nuevos CTAs (Call to Action) optimizados.
  - Identificación de KPIs críticos para el negocio.
  - Análisis profundo del comportamiento de las reservas (Pasadas, Presentes y Futuras).
- **Valor**: Pasar de una gestión reactiva a una proactiva basada en predicciones de la IA.
